以下是在 Git Gud 挑戰中使用的終端機與 Git 指令。

Bash/終端機基礎

  • 顯示你所在的資料夾（print working directory）
    • pwd
  • 列出資料夾中的項目
    • ls
  • 列出所有東西，包括隱藏項目
    • ls -a
  • 列出詳細資訊 — 開頭的 d 表示目錄
    • ls -l
  • 進入既有資料夾（也就是切換目錄）
    • cd <FOLDERNAME>
  • 回到上一層資料夾
    • cd ..
  • 前往你的家目錄
    • cd ~
  • 回到上一個資料夾
    • cd -
  • 建立新資料夾（也就是 make directory）
    • mkdir <FOLDERNAME>
  • 一次建立一整串資料夾
    • mkdir -p <A>/<B>/<C>
  • 建立空檔案
    • touch <FILENAME>
  • 把某段文字顯示給你看
    • echo hello
  • 清空視窗（不會刪除任何東西）
    • clear
  • 關閉終端機
    • exit
  • 詢問任何指令它能做什麼
    • <COMMAND> --help

比任何指令都重要的兩個按鍵： Tab 會自動補完你 開始輸入的檔案或資料夾名稱，而 up arrow 會叫回 你之前輸入的內容。

設定 Git

  • 查看 Git 版本
    • git --version
  • 設定你的名稱
    • git config --global user.name "Your Name"
  • 設定你的電子郵件
    • git config --global user.email youremail@example.com
  • 設定你的 Github 帳號（區分大小寫）
    • git config --global user.username uSeRnAmE

Git 基礎

  • 為資料夾啟用 Git
    • git init
  • 查看儲存庫的變更狀態
    • git status
  • 查看檔案的變更
    • git diff
  • 把檔案的變更加入待提交區
    • git add <FILENAME>
  • 加入所有檔案的變更
    • git add .
  • 提交（也就是儲存）你已加入的變更，並附上一段描述變更的簡短訊息
    • git commit -m "your commit message"
  • 把儲存庫複製到你的電腦
    • git clone <URL>

Git 分支

  • 建立新分支
    • git branch <BRANCHNAME>
  • 切換到某個分支
    • git checkout <BRANCHNAME>
  • 你可以用一行指令建立並切換到分支
    • git checkout -b <BRANCHNAME>
  • 列出分支
    • git branch
  • 重新命名你所在的分支
    • git branch -m <NEWBRANCHNAME>

Git 遠端

  • 新增遠端連線
    • git remote add <REMOTENAME> <URL>
  • 為遠端設定 URL
    • git remote set-url <REMOTENAME> <URL>
  • 查看遠端連線
    • git remote -v

在 Git 中拉取

  • 拉取變更
    • git pull
  • 從遠端分支拉取變更
    • git pull <REMOTENAME> <REMOTEBRANCH>
  • 在拉取之前先查看遠端的變更
    • git fetch --dry-run

Git 中的推送 & 合併

  • 推送變更
    • git push <REMOTENAME> <BRANCHNAME>
  • 把分支合併進目前的分支
    • git merge <BRANCHNAME>

在 Git 中刪除遠端與分支

  • 刪除本地分支
    • git branch -D <BRANCHNAME>
  • 刪除遠端分支
    • git push <REMOTENAME> --delete <BRANCHNAME>
