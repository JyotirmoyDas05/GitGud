GitHub Desktop

你很可能在開始 Git Gud 之前就已經安裝了它，但如果還沒，這裡是連結。

GitHub Desktop 應用程式能做到你在終端機中能做的大部分事情（雖然不是全部），而且有時更容易閱讀。就我個人而言，我會用它來檢查任何不小的 diff。用這種方式看你的變更 真的很清楚。

  • Github Desktop （OSX、Windows）免費，由 GitHub 提供
  • Github Desktop Guides 由 GitHub 提供

你可以在 Git 官網上查看更多桌面版 Git 應用程式：Git GUIs
