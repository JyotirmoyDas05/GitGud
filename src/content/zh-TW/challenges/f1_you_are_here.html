找出你的終端機站在哪裡，看看周圍有什麼，並認出你的家目錄。

終端機永遠在某個地方

有一個想法能讓其他一切都通了：你的終端機永遠在恰好一個資料夾裡面。不是「開在」它——而是站在它裡面，就像檔案總管視窗一次只顯示一個資料夾一樣。

那個資料夾叫做目前目錄，或工作目錄。除非你另有說明，你輸入的每個指令都在 那裡 發生。ls 列出那個資料夾。mkdir notes 在它裡面建立新資料夾。之後的 git init 會把 那個 資料夾變成儲存庫——所以「我在哪個資料夾？」不再是冷知識，而是行動前要檢查的事。

新手在終端機裡幾乎每一次困惑——「檔案明明就在眼前卻說不存在」——都是這個。檔案存在。你站錯地方了。

目錄就是資料夾

目錄和資料夾是同一個東西。「資料夾」是圖形桌面取的名字；「目錄」是更老的名字，終端機、文件和每個指令名稱用的都是它——mkdir 就是 make directory，cd 就是 change directory。看到兩個詞，都當同一個意思就好。

你的電腦存兩種東西：

  • 檔案裝內容——文字、照片、程式碼。
  • 目錄裝別的檔案和目錄。就這樣而已。

目錄裡面有目錄，裡面還有目錄，從一個起點一路往下。那個巢狀就是 檔案系統，它是一棵樹。

顯示你在哪裡

打開你的終端機。每個終端機使用者都學會信任的第一個指令：

pwd

print working directory 的縮寫。它用完整地址回答問題：

/Users/jyoti

在 Git Bash 的 Windows 上你會看到像 /c/Users/jyoti 的東西——同一個地方，Git Bash 只是把 C: 碟用 Unix 寫法寫出來。

那個地址叫做路徑。由左往右當作指引來讀：從最頂端開始，進到 Users，再進到 jyoti。每個 / 就是再往裡一步。像這樣從最頂端開始的路徑是絕對路徑——不管你站在哪裡用，意思都一樣。

pwd 免費、即時、什麼都不改。不確定的時候就執行。沒人會因為你執行 pwd 而看輕你。

看看四周

看看這裡實際上有什麼：

ls

Desktop Documents Downloads Music Pictures

認得嗎？跟你在檔案總管看到的是同樣的資料夾，因為沒有什麼「終端機專用檔案系統」——是一台電腦、兩種看法。把檔案總管拉到終端機旁邊並排一次。整個感覺就沒那麼抽象了。

要一眼分出檔案和目錄，要求詳細版：

ls -l

drwxr-xr-x 5 jyoti staff 160 Sep 20 09:12 Documents -rw-r--r-- 1 jyoti staff 1024 Sep 20 09:14 notes.txt

現在先忽略幾乎全部，只看每一行的第一個字。 d 是 目錄 的意思。 - 是普通 檔案。那一個字母就是答案。

家，和波浪符號

打開終端機時，它不是從隨機位置開始的。它從你的 家目錄 開始——屬於你的使用者帳號的那個資料夾，裝著你的桌面、文件和下載。

  • macOS：/Users/yourname
  • Linux：/home/yourname
  • Windows：C:\Users\yourname，Git Bash 會顯示為 /c/Users/yourname

你會一直輸入它，所以它有個捷徑：~，波浪符號。凡是能寫路徑的地方， ~ 就是「我的家目錄」的意思。所以 ~/Documents 就是你的文件資料夾，在每台機器、每個使用者手上寫法都一樣——這正是文件裡滿滿波浪符號的原因。

回頭看你的提示字元。裡面的那個 ~ 是同一個捷徑：提示字元在告訴你你在家。走進子資料夾，看著它變成 ~/Documents。你的提示字元一直靜靜地在回答 pwd。

證明它

打開終端機，去別處之前先執行 pwd，讀它顯示的路徑。那就是你的家目錄。

再用下面的 Select directory 選取那個完全相同的資料夾。Git Gud 會自己算出你的家目錄在哪裡並比對——所以這是有對錯的真答案，不是勾選框。

順便也執行 ls，再用 exit 讓殼層存檔，按 Verify。
