用 cd 在檔案系統裡移動——走進資料夾、回到上一層，再直直回家。

切換目錄

你知道自己在哪裡了。現在要去別的地方。一個指令搞定：

cd <WHERE>

cd 就是 change directory。它等於在終端機裡雙擊資料夾，也是你往後人生打最多次的指令。

成功的時候它什麼都不顯示。那種安靜是正常的、故意的——在終端機裡，沒消息就是好消息。出錯時指令才會出聲。它成功了的證據是提示字元，現在顯示新資料夾了，以及 pwd 會替你確認。

走進資料夾

從家開始，先看看有什麼：

cd ~ ls

挑一個你看到的資料夾——Documents 和 Desktop 幾乎每台機器都有——走進去：

cd Documents

看提示字元。變了。好好確認：

pwd

/Users/jyoti/Documents

你剛剛用了相對路徑。你只打了 Documents 而不是完整地址，卻成功了，因為 cd 是 從你已經站的地方出發 去找那個名字的。相對路徑很短，意思隨站立位置而變——重點就在這裡。

輸入 cd Doc 再按 Tab。殼層會幫你把字補完。這就是Tab 補全，以後你打的每條路徑都通用，既省按鍵也防打錯。現在就養成習慣——覺得終端機無聊的人和不覺得的人，差別就在這裡。

回到上一層

每個目錄都有一個父層——裝著它的那一個。它有個永久的縮寫，兩個點：

cd .. pwd

你回到出發點了。.. 永遠是「從這裡往上一層」的意思，所以不用知道名字，到哪裡都通用。

還有個成對的縮寫：一個點 .，意思是「就是這裡」。看似沒用——直到你遇到一個要你親口說「這個資料夾」的指令。你之後會打很多次的 git add . 正是那樣。

點可以疊加。這行往上兩層：

cd ../..

也可以跟名字組合。往上一層再走進隔壁資料夾，一步完成：

cd ../Downloads

詞彙就這些。路徑只是把這些零件用斜線接起來。

絕對和相對

兩種路徑，分清手上拿的是哪一種，大多數路徑困惑就一勞永逸了。

  • 絕對路徑從檔案系統最頂端開始，自己就是完整的：/Users/jyoti/Documents。從哪裡打意思都一樣。認法一秒——以 / 開頭（或 ~，會展開成絕對路徑，Windows 上則是 C: 這類磁碟機代號）。
  • 相對路徑從你站的地方開始：Documents、../Downloads、notes/day-one.txt。比較好打，但只有從正確的起點出發才對。

想成住址跟「左手邊第二間」的差別。兩個都到得了。只有一個講給站在別處的人聽還管用。

附近的東西——大多數時候都是——用相對路徑。要跳很遠，或要把路徑寫給別人，就拿出絕對路徑。

跳到任何地方

先晃到深幾層的地方，再一步回家：

cd ~

後面什麼都不加的 cd 效果一樣——家是預設目的地，因為你會常想回去，常到值得一個捷徑。

絕對路徑則不管多遠，一步就到任何地方：

cd ~/Documents

這是絕對路徑——~ 會在 cd 看到之前，先展開成你家目錄的完整地址。在 macOS 或 Linux 上你也可以直接瞄準整個檔案系統的最頂端去逛逛；那裡的東西不會咬你。

cd / ls

最後一個值得收下的捷徑：

cd -

那會帶你回上一個目錄，像瀏覽器的上一頁。連打兩次就在兩個資料夾之間來回——實際工作多半就是這樣。

檢查什麼

這個挑戰在你的殼層歷史裡找四種不同 形狀 的 cd——上面每個概念各一，而不是四個特定地點，所以用你實際有的資料夾練習就行：

  • cd Documents — 用名字走進資料夾（相對）
  • cd .. — 回到父層
  • cd ~ — 家
  • cd ~/Documents 或 cd /usr — 絕對路徑

每次之後都執行 pwd 看它運作。再用 exit 存檔並按 Verify。

到處走

  • 走進資料夾
    • cd <FOLDERNAME>
  • 回到父層
    • cd ..
  • 上兩層，或上去再跨過去
    • cd ../../
  • 家
    • cd ~
  • 回剛才的地方
    • cd -
  • 不確定的時候永遠
    • pwd
