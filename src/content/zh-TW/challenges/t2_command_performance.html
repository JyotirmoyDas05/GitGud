學會每個指令都由哪三個部分組成，以及如何問指令本身它會做什麼。

指令、引數、選項

你在提示字元輸入的每一行形狀都一樣。一旦看出來，陌生的指令就不再像魔法咒語，而像句子了。

command [options] [arguments]

  • 指令是動詞——你想執行的程式。永遠擺第一個。ls、echo、git 都是。
  • 引數是指令要作用的對象。就是名詞。在 cd Documents 裡，引數是 Documents。
  • 選項（又叫 旗標 或 開關）改變指令運作的 方式。以破折號開頭：-a、-l、--help。

所以 ls -l Documents 讀作：列出來（指令）、用詳細版（選項）、Documents 資料夾（引數）。三個部分，用空白隔開。

這個間隔比新手想像的重要得多。ls-l 是一個單字，殼層會告訴你沒有這種指令。殼層就是靠空白知道一個部分在哪裡結束、下一個從哪裡開始。

短選項和長選項

大多數選項對同一件事有兩種寫法：

  • 短的，一個破折號加一個字母：-a。好打。通常可以合併——ls -la 就是 -l 加 -a 的意思。
  • 長的，兩個破折號加一個單字：--all。比較難打，但半年後讀回來還知道它做了什麼。

自己打字的時候用短的，寫下來給別人看的時候用長的——包括未來的你。

帶引數的指令

echo 只做一件事：把你給它的東西顯示回來。

echo hello

hello

單獨的 echo 後面什麼都不加，會顯示一個空行——沒有引數的指令無話可說。給它好幾個單字，它就全部顯示：

echo I am talking to my computer

看起來沒用。其實不是：echo 是你在做危險操作前確認內容的方法，也是指令碼不如預期時你第一個會拿起來的工具。

帶選項的指令

ls 會列出你目前站的資料夾裡有什麼。先不加東西試一次：

ls

再加個選項，看同一個指令如何換一種回答：

ls -a

-a 是 all 的縮寫，突然多出好多以點開頭的項目——.bashrc、.gitconfig。開頭的點意思是「隱藏」，隱藏只是說 ls 沒被要求就不顯示。跟權限無關，它們是名字低調的普通檔案。Git 就把整個儲存庫放在其中一個裡面，之後會遇到。

再一個：

ls -l

-l 是 long 的意思——一行一項，附上大小和上次修改時間。同樣的指令、同樣的資料夾，因為你開口要求，詳細程度就不一樣。

短選項可以合併，所以這行一次做兩件事：

ls -la

直接問指令本身

沒人背得下選項。老手真正做的是問，而幾乎每個指令都會回答同一個問題：

ls --help

會跑出一大片文字。不用全讀——讀前面幾行知道這個指令是做什麼的，再沿著左邊的選項清單找到看起來像你想要的。那個技巧是瀏覽，不是背誦。

拿一個你這輩子沒用過的指令試試：

mkdir --help

沒人教你，你也知道 mkdir 是做什麼的、大概怎麼用了。讓終端機變得可學、而不是待背清單的，就是這一招——而 mkdir 再過兩個挑戰就會正式登場。

在 macOS 上，有些指令用 man ls 回答而不是 --help——man 是 manual 的縮寫。按 q 離開。

清掉雜亂

輸出這麼多之後視窗一團亂。一個指令搞定：

clear

什麼都沒刪——歷史還在，上箭頭還能用。只是把雜訊捲走，讓你可以思考。

當你用 echo 講了些話、用 ls 加了選項、對任何東西用了 --help，就用 exit 關掉終端機讓殼層存檔，再按 Verify。

每次都一樣的形狀

  • 單獨的指令
    • ls
  • 帶選項的指令
    • ls -a
  • 帶引數的指令
    • echo hello
  • 三種合在一起
    • ls -l Documents
  • 問指令它是做什麼的
    • ls --help
