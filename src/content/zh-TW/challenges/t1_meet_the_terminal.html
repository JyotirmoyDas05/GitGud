什麼是終端機

終端機是一個讓你用輸入指令來指揮電腦的視窗，而不是用點擊。這就是全部的概念。你已經會做的每件事——開啟資料夾、新增資料夾、重新命名檔案、複製東西——都有對應的輸入版本，而輸入版通常更快，也一定可以重複執行。

你會聽到幾個意思差不多的詞，值得一次搞清楚：

  • 終端機是視窗本身。它顯示文字並接收你的按鍵。
  • 殼層是在裡面真正運作、理解你輸入內容的程式。常見的有 Bash、Zsh 和 PowerShell。
  • 命令列和 CLI 是這種工作方式的通用名稱。

實際上大家會把四個詞混著用，我們也會這樣。如果有人叫你「打開終端機」，指的就是這個視窗。

它看起來嚇人是因為空空的，而且沒告訴你要做什麼。但它並不危險。這個模組裡沒有任何東西會壞掉——你只是顯示自己的使用者名稱、建立一個練習用資料夾。沒有人會評斷你的輸入。

打開你的終端機

Windows。 Windows 內建 PowerShell，但這個模組的指令——以及你以後讀到的幾乎每一篇教學、README 和 Stack Overflow 回答——都是為 Unix 風格殼層寫的。最簡單的方法是 Git Bash，隨 Git for Windows 免費附帶。用預設選項安裝，再從開始選單開啟 Git Bash。

這個安裝也會把你稍後需要的 Git 裝進電腦——後面的挑戰會確認它有正確設定好。一舉兩得。

macOS。 按下 Cmd + Space，輸入 Terminal，按 enter。它也在應用程式 › 工具程式裡。

Linux。 通常是 Ctrl + Alt + T，或在應用程式中搜尋 Terminal。

你現在應該會看到一個幾乎空白的視窗，只有一行文字和閃爍的游標。那一行就是接下來要理解的東西。

讀懂提示字元

等著你的那一行叫做提示字元。它不是裝飾——它是狀態列，在你還沒輸入任何東西之前，就先告訴你三件有用的事。

jyoti@laptop ~/code $

  • jyoti — 你是用什麼身分登入的。
  • laptop — 你在跟哪一台機器說話。等你開始連到別台電腦，就會發現這比想像中重要。
  • ~/code — 你在哪裡。終端機永遠站在某個資料夾裡，就是這裡。下下個挑戰整篇都在講這部分。
  • $ —「換你了」的意思。它後面才是你要輸入的東西。

你的長得會不一樣。macOS 上的 Zsh 常常以 % 結尾而不是 $，有些提示字元是兩行，有些是彩色的，有些會顯示目前的 Git 分支。位置會變，概念不變。

這也是為什麼文件會在指令前面寫一個 $——那是「在你的提示字元輸入這個」的簡寫。你永遠不用輸入 $ 本身。Git Gud 的程式碼方塊裡也有它，但複製按鈕會自動略過。

打聲招呼

輸入下面這行並按下 enter：

whoami

它會顯示你的使用者名稱。就這樣。這就是這個指令的全部。

jyoti

再試一個：

date

按下上箭頭。你的殼層記得你輸入過什麼，會把它還給你。多按幾次。這是這一頁最省時間的一招。

關閉終端機

點視窗的關閉鈕也可以。但有個正式的方法，而且它跟其他指令一樣，也是一個指令：

exit

視窗關掉了。用剛才一樣的方法重開——終端機是便宜又用完即丟的東西，你一天會不經意地開關好幾十次。

偏好 exit 的一個理由：你輸入過什麼的記憶存在檔案裡，而 Bash 和 Zsh 只在殼層正常關閉時才寫出去。這就接到這個挑戰的檢查方式了。

Git Gud 如何檢查

whoami 這類指令不會改變電腦上的任何東西，所以事後沒有資料夾或檔案可以看。Git Gud 改讀你自己殼層保留的歷史檔——Bash 是 ~/.bash_history，Zsh、Fish 和 PowerShell 則是對應的檔案——來找這個挑戰要求的指令。

它只讀最後幾百行，只在你的電腦上讀，什麼都不會傳出去。下面的每一項檢查都會寫明它讀了哪個確切檔案。

所以：執行 whoami 和 date，再用 exit 關掉終端機讓殼層存檔，開一個新的，回來這裡按 Verify。

如果檢查看不到你的指令

Bash 和 Zsh 是在殼層 結束 時才存歷史，而不是邊打邊存。如果你做了但檢查找不到，幾乎一定是終端機還開著。輸入 exit 再按一次 Verify。

在 Windows 上，cmd.exe 完全不留歷史。請用 Git Bash 或 PowerShell。
