Move around the filesystem with cd — down into folders, back up to the parent, and straight home again.

Changing Directory

You know where you are. Now you need to be somewhere else. One command does it:

cd <WHERE>

cd is change directory. It's the terminal's equivalent of double-clicking a folder, and it's the command you'll type more than any other for the rest of your life.

It prints nothing when it works. That silence is normal and it's deliberate — in the terminal, no news is good news. Commands speak up when something goes wrong. Your proof it worked is the prompt, which now shows the new folder, and pwd, which will confirm it.

Go Down Into a Folder

Start at home and look at what's there:

cd ~ ls

Pick any folder you saw — Documents and Desktop exist on nearly every machine — and go into it:

cd Documents

Check the prompt. It changed. Confirm it properly:

pwd

/Users/jyoti/Documents

You just used a relative path. You typed Documents, not the whole address, and it worked because cd looked for that name starting from wherever you already were. Relative paths are short, and they mean different things depending on where you're standing — which is the point.

Type cd Doc and press Tab. The shell finishes the word for you. This is tab completion, it works on every path you will ever type, and it saves you from typos as well as keystrokes. Get in the habit now — it's the difference between people who find the terminal tedious and people who don't.

Go Back Up

Every directory has a parent — the one that contains it. It has a permanent shorthand, two dots:

cd .. pwd

You're back where you started. .. always means "one level up, from here", so it works anywhere without knowing any names.

There's a matching shorthand for the opposite: a single dot, ., means "right here". It looks useless — until you meet a command that needs you to say "this folder" out loud. git add ., which you'll type many times later, is exactly that.

Dots stack. This goes up two levels:

cd ../..

And they combine with names. Up one level, then down into a sibling folder, in a single move:

cd ../Downloads

That's the whole vocabulary. A path is just these pieces joined with slashes.

Absolute and Relative

Two kinds of path, and knowing which one you're holding removes most path confusion for good.

  • An absolute path starts from the top of the filesystem and is complete on its own: /Users/jyoti/Documents. It means the same thing typed from anywhere. You can spot one instantly — it begins with / (or ~, which expands into one, or a drive letter like C: on Windows).
  • A relative path starts from wherever you are: Documents, ../Downloads, notes/day-one.txt. Shorter to type, but only correct from the right starting point.

Think of it as a street address versus "second door on the left". Both get you there. Only one of them survives being repeated to someone standing somewhere else.

Use relative paths for anything nearby — that's most of the time. Reach for an absolute path when you're jumping somewhere far away, or when you're writing the path down for someone else.

Jump Anywhere

Wander somewhere a few levels deep, then go home in one move:

cd ~

cd with nothing after it does the same thing — home is the default destination, because that's where you'll want to be often enough that it earned the shortcut.

And an absolute path takes you anywhere in one step, no matter how far:

cd ~/Documents

That's absolute — ~ expands to the full address of your home directory before cd ever sees it. On macOS or Linux you can also aim at the very top of the whole filesystem and have a look around; nothing there will bite you.

cd / ls

One last shortcut worth having:

cd -

That takes you back to the previous directory, like the back button in a browser. Two of those in a row and you're toggling between two folders — which is most of what real work looks like.

What Gets Checked

This challenge looks for four different shapes of cd in your shell history — one for each idea above — rather than four particular destinations, so you can practise with whatever folders you actually have:

  • cd Documents — down into a folder by name (relative)
  • cd .. — up to the parent
  • cd ~ — home
  • cd ~/Documents or cd /usr — an absolute path

Run pwd after each one so you can see it working. Then exit to save your history and press Verify.

Getting Around

  • Into a folder
    • cd <FOLDERNAME>
  • Up to the parent
    • cd ..
  • Up two, or up one and across
    • cd ../../
  • Home
    • cd ~
  • Back to where you just were
    • cd -
  • And always, when unsure
    • pwd
