Git Gud teaches the everyday Git commands developers actually use, along with the GitHub Flow — the way people collaborate on GitHub. It starts earlier than most tutorials do: the first five challenges are about the terminal itself, because "open a terminal and run git init" is not one instruction if you have never opened a terminal.

Some challenges need an internet connection, so you'll want to be online to finish. You can always open the app and read the challenges and resources offline.

A real development environment

Git Gud uses the real terminal, real Git and real GitHub rather than emulating any of them. When you finish you'll have actual repositories on your GitHub account and green squares on your contribution chart. Nothing here is a simulation, which is also why each challenge is checked by running Git against your own repositories — if a challenge passes, it genuinely worked.

What you need

Nothing, to begin with — the terminal module uses what your computer already has. After that, Git and a GitHub account, which two of the challenges walk you through. You do not need Node.js, Python, or any other runtime — Git Gud ships as a single native application.

About the terminal challenges

Commands like pwd and ls change nothing on your computer, so there is no file to inspect afterwards to see whether you ran them. Those challenges are checked by reading the history file your own shell keeps — ~/.bash_history and its equivalents for Zsh, Fish and PowerShell. Only the most recent few hundred lines are read, it happens entirely on your machine, nothing is sent anywhere, and each check names the file it read.

How it's built

Git Gud is a Tauri application: a Rust backend that runs Git and talks to GitHub, and a React interface rendered by the operating system's own web view. There's no bundled browser engine, which is why the download is measured in megabytes rather than hundreds of them.

The companion repository you fork during the challenges is git-gud-verifywork. Its automation runs entirely on GitHub Actions — there is no server to go down.

Credit where it's due

Git Gud is a port of Git-it, an Electron app written by @jlord and many contributors, released under the BSD 2-Clause licence. The challenge structure and much of the writing are theirs. This version rebuilds the application on Tauri, replaces the retired verification service with GitHub Actions, and fixes a number of checks that had stopped working as Git and GitHub changed.

The interface design borrows its token system from T3 Code, used under the MIT licence.
