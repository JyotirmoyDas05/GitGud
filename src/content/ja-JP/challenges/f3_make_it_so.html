mkdir と touch でターミナルから小さなフォルダツリーを作りましょう。

ものを作る

ここまでは読み取り専用でした——見て、移動するだけです。作る作業のほぼすべては2つのコマンドで足ります:

  • mkdir — make directory の意味。フォルダを作ります。
  • touch — 空のファイルを作ります。

どちらも、別の道筋を示すパスを渡さない限り、今立っているディレクトリの中に作ります。ここで前のチャレンジが効いてきます: 新しいフォルダがどこにできるか不安なら、まず pwd を実行してください。

touch という奇妙な名前は、ファイル作成が本業ではないからです——本来の目的はファイルのタイムスタンプ更新であり、まだ存在しないものを作るのはついでの偶然でした。皆がその偶然のために使っています。

練習用フォルダを作る

作り場所に疑いがないよう、ホームから始めます:

cd ~

フォルダを作って中に入ります:

mkdir gitgud-practice cd gitgud-practice

cd と同じく、 mkdir はうまくいっても何も言いません。安心したければ ls で確認してください——最初の数回はそうすべきです。

名前は必ず gitgud-practice にしてください——チェックはその名前を探します。スペースがないことにも注意してください。名前のスペースは合法ですが入力しづらくなるため、プログラミングの世界ではハイフンが好まれます。

ファイルを作る

今いる場所は gitgud-practice の中のはずです。よければ確認してください:

pwd

次に空ファイルを作ります:

touch hello.txt ls

hello.txt

存在し、中身は空です——0バイトです。 touch は容器を作ります。中に何か入れるのはテキストエディタの仕事です。よければ好きなエディタで開いて何か入力してください。ここでは何も依存しません。

フォルダを作り、その中にファイルを作る

まだ gitgud-practice の中にいます:

mkdir notes

ここが役立つ点です——notes の中に 中に入らずに ファイルを作ります。ただの名前ではなく相対パスを touch に渡します:

touch notes/day-one.txt

その引数はパスとして読みます: フォルダ notes の中の day-one.txt というファイル。コマンドはどこでも名前だけでなくパスを受け取ります。1つの作業のためだけにわざわざ cd する必要はほぼありません。

作業を確認します:

ls notes

ls no と入力して Tab を押してください。タブ補完は今作ったフォルダにも他のものと同じく使えます——おかげで入力ミスを防げます。入力ミスがなければ「No such file or directory」を眺めて1分悩まずに済みます。

複数のフォルダを一度に

入れ子のフォルダを素直な方法で作ろうとして、拒まれる様子を見てみましょう:

mkdir notes/archive/2026

mkdir: cannot create directory 'notes/archive/2026': No such file or directory

もっともです—— archive はまだ存在せず、 mkdir は連鎖ではなく1つのディレクトリを作ります。各階層を手作りする代わりに、そう頼みます:

mkdir -p notes/archive/2026 ls notes

-p は parents の略です: 途中で欠けているフォルダも作ります。これは2つ前のチャレンジの規則が動いています——同じコマンドに1つのオプションで動作が変わり、 mkdir --help が教えてくれたはずのことです。

ツリーは今こうなっています:

gitgud-practice/ ├── hello.txt └── notes/ ├── day-one.txt └── archive/ └── 2026/

チェック内容

2つを合わせた内容です。Git Gudは gitgud-practice フォルダを読んでツリーが本当にあるか確認し、かつシェル履歴で mkdir と touch を確認します——右クリックの新規フォルダーでも作れてしまい、このモジュールの趣旨ではないからです。

下のSelect directoryで自分の gitgud-practice フォルダを選び、履歴保存のために exit でターミナルを閉じてVerifyを押してください。

終わったらフォルダは残しても消してもかまいません——後は何にも依存しません。同じ2つのコマンドで、すぐに本物のプロジェクトフォルダを作ります。

ものを作る

  • フォルダを作る
    • mkdir <FOLDERNAME>
  • フォルダの連鎖を一気に作る
    • mkdir -p <A>/<B>/<C>
  • 空ファイルを作る
    • touch <FILENAME>
  • 別のフォルダの中に作る
    • touch <FOLDERNAME>/<FILENAME>
  • うまくいったか確認する
    • ls <FOLDERNAME>

ターミナルモジュールは以上です。ターミナルを開き、プロンプトを読み、オプションと引数付きでコマンドを実行し、今いる場所を調べ、別の場所へ行き、着いたらものを作れます。これからGitが求めるのは、言葉が違うだけで同じ動きです。
