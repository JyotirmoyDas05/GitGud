cd でファイルシステムを移動しましょう——フォルダの中へ、親へ、そしてまっすぐホームへ戻ります。

ディレクトリの変更

今いる場所が分かりました。次は別の場所へ行く必要があります。そのためのコマンドは1つです:

cd <WHERE>

cd は change directory の意味です。フォルダをダブルクリックする操作のターミナル版であり、今後の人生で最も多く入力するコマンドになります。

うまくいっても何も表示しません。その沈黙は正常で意図的です——ターミナルでは、何も言わないのが良い知らせです。何か問題があるときにコマンドは声を上げます。うまくいった証拠は、新しいフォルダを示すプロンプトと、それを裏付ける pwd です。

フォルダの中へ進む

ホームから始めて、何があるか見てみましょう:

cd ~ ls

見えたフォルダを1つ選んでください—— Documents と Desktop はほぼすべてのマシンにあります——中に入ります:

cd Documents

プロンプトを見てください。変わりました。きちんと確認しましょう:

pwd

/Users/jyoti/Documents

相対パスを使いました。全体の住所ではなく Documents と入力したのに動いたのは、 cd が今いる場所を起点にその名前を探したからです。相対パスは短く、立っている場所によって意味が変わります——そこが要点です。

cd Doc と入力して Tab を押してください。シェルが単語を補完してくれます。これがタブ補完であり、今後入力するすべてのパスで使え、入力の手間だけでなく入力ミスも防いでくれます。今のうちに習慣にしましょう——ターミナルを面倒に感じる人とそうでない人の差はここです。

上へ戻る

すべてのディレクトリには親——それを含む側——があります。永続的な略記があり、2つのドットです:

cd .. pwd

開始地点に戻りました。 .. は常に「ここから1段上」という意味なので、名前を知らなくてもどこでも使えます。

対になる略記もあります: 1つのドット . は「まさにここ」という意味です。無用に見えますが——「このフォルダ」と声に出して言う必要があるコマンドに出会うまでは。後に何度も入力する git add . がまさにそれです。

ドットは重ねられます。これは2段上がります:

cd ../..

名前とも組み合わせられます。1段上がってから隣のフォルダへ降りる動きを1回で:

cd ../Downloads

語彙はこれだけです。パスとはこれらの部品をスラッシュでつないだものにすぎません。

絶対パスと相対パス

2種類のパスがあり、どちらを持っているか分かれば、ほとんどのパス混乱はきれいに解消します。

  • 絶対パスはファイルシステムの頂上から始まり、それ単体で完全です: /Users/jyoti/Documents。どこから入力しても同じ意味です。見分け方は一瞬です—— / で始まります(または ~。展開すると絶対パスになります。Windowsでは C: のようなドライブ文字です)。
  • 相対パスは今いる場所から始まります: Documents、../Downloads、notes/day-one.txt などです。入力は短いですが、正しい起点からのみ正しくなります。

住所と「左側の2番目のドア」の違いだと考えてください。どちらでもたどり着けます。別の場所にいる人に伝えても通じるのは片方だけです。

近くのもの——たいていはこちらです——には相対パスを使いましょう。遠くへ一気に跳ぶときや、誰かのためにパスを書き残すときは絶対パスを使います。

どこへでも跳ぶ

数段深いところまでさまよってから、1回でホームに戻りましょう:

cd ~

何も付けない cd も同じことです——ホームが既定の行き先です。行きたくなることが十分多いため略記が与えられました。

絶対パスなら距離に関係なく1手順でどこへでも行けます:

cd ~/Documents

これは絶対パスです—— ~ は cd が見る前にホームディレクトリの完全な住所に展開されます。macOSやLinuxではファイルシステム全体の頂上を目指して周りを見てもかまいません。そこにあるものが噛みつくことはありません。

cd / ls

最後に持っておく価値のある略記です:

cd -

直前のディレクトリに戻ります。ブラウザの戻るボタンのようなものです。これを2回続ければ2つのフォルダを行き来します——実際の作業のほとんどはその繰り返しです。

チェック内容

このチャレンジではシェル履歴から4種類の形の cd を探します——上の考え方に1つずつ対応し、行き先そのものは問いません。実際にあるフォルダで練習できます:

  • cd Documents — 名前でフォルダの中へ(相対)
  • cd .. — 親へ上る
  • cd ~ — ホーム
  • cd ~/Documents または cd /usr — 絶対パス

それぞれの後に pwd を実行して動作を確認してください。次に履歴保存のため exit してVerifyを押します。

移動方法

  • フォルダの中へ
    • cd <FOLDERNAME>
  • 親へ上る
    • cd ..
  • 2段上へ、または上へ行って横へ
    • cd ../../
  • ホーム
    • cd ~
  • 直前にいた場所へ戻る
    • cd -
  • 迷ったらいつでも
    • pwd
