ターミナルが今どこに立っているかを確認し、周りを見渡して、ホームディレクトリを特定しましょう。

ターミナルは常にどこかにいる

他のすべてが腑に落ちる1つの考え方があります: ターミナルは常にちょうど1つのフォルダの中にいます。「そのフォルダで開いている」のではなく、ファイルエクスプローラのウィンドウが一度に1つのフォルダを表示しているのと同じように、その中に立っています。

そのフォルダを カレントディレクトリ、または作業ディレクトリと呼びます。別に指定しない限り、入力するすべてのコマンドはそこで実行されます。ls はそのフォルダを一覧表示します。 mkdir notes はその中に新しいフォルダを作ります。後に出てくる git init はそのフォルダをリポジトリに変えます——だから「今どのフォルダにいるか」は雑学ではなく、行動前に確認するものになります。

初心者がターミナルでほぼ必ず混乱する瞬間——「ファイルはそこに見えるのに存在しないと言われる」——はこれが原因です。ファイルは存在します。立っている場所が違うのです。

ディレクトリはフォルダのこと

ディレクトリとフォルダは同じものです。「フォルダ」はグラフィカルなデスクトップでの呼び名で、「ディレクトリ」は古い名前であり、ターミナルやドキュメント、すべてのコマンド名で使われる方です—— mkdir は make directory、cd は change directory の意味です。両方の言葉を目にしたら、同じものだと思ってください。

コンピュータが保存するものは2種類です:

  • ファイルは中身を持ちます——テキスト、写真、コードなどです。
  • ディレクトリは他のファイルやディレクトリを保持します。それだけです。

ディレクトリの中にディレクトリ、その中にさらにディレクトリと、1つの起点からずっと続きます。その入れ子が ファイルシステム であり、木構造になっています。

今いる場所を表示する

ターミナルを開いてください。すべてのターミナルユーザーが信頼するようになる最初のコマンドです:

pwd

print working directory の略です。完全な住所で質問に答えます:

/Users/jyoti

Git BashのWindowsでは /c/Users/jyoti のように見えます——同じ場所で、Git Bashが C: ドライブをUnix風に書いているだけです。

その住所を パス と呼びます。左から右へ道順として読みます: 一番上から始めて Users に入り、次に jyoti に入ります。 / が1つあるたびに1段奥へ進みます。このように一番上から始まるパスは絶対パスといい、どこに立って使う場合でも同じ意味になります。

pwd は無料で一瞬、何も変更しません。迷ったらいつでも実行してください。 pwd を実行したからといって誰も馬鹿にしません。

周りを見る

実際にここにあるものを見てみましょう:

ls

Desktop Documents Downloads Music Pictures

見覚えがありませんか?ファイルエクスプローラで見るのと同じフォルダです。なぜなら「ターミナル専用のファイルシステム」はなく、1台のコンピュータを2通りの方法で見ているだけだからです。一度だけファイルエクスプローラをターミナルの横に並べてみてください。全体が抽象的に感じられなくなります。

ファイルとディレクトリを一目で見分けるには、詳細表示を求めます:

ls -l

drwxr-xr-x 5 jyoti staff 160 Sep 20 09:12 Documents -rw-r--r-- 1 jyoti staff 1024 Sep 20 09:14 notes.txt

今はほぼすべて無視して、各行の最初の1文字だけを見てください。 d はディレクトリ、 - は普通のファイルという意味です。その1文字が答えです。

ホームとチルダ

ターミナルを開いたとき、開始位置はランダムではありません。 ホームディレクトリから始まります——皆さんのユーザーアカウントに属するフォルダで、デスクトップやドキュメント、ダウンロードが入っている場所です。

  • macOS: /Users/yourname
  • Linux: /home/yourname
  • Windows: C:\Users\yourname、Git Bashでは /c/Users/yourname と表示されます

常に入力するので略記があります: ~、チルダです。パスを書く場所ならどこでも、 ~ は「自分のホームディレクトリ」という意味です。つまり ~/Documents はドキュメントフォルダであり、どのマシンでもどのユーザーでも同じ書き方です——だからこそドキュメントはチルダだらけなのです。

プロンプトを振り返ってみてください。その中の ~ は同じ略記です: プロンプトはホームにいることを伝えています。サブフォルダに入ると ~/Documents に変わるはずです。プロンプトはずっと静かに pwd に答えていたのです。

証明する

ターミナルを開き、どこにも移動する前に pwd を実行して、表示されたパスを読んでください。それが皆さんのホームディレクトリです。

次に下のSelect directoryを使って、そのフォルダをそのまま選んでください。Git Gudはホームディレクトリの場所を独自に算出して比較します——チェックボックスではなく、正解と不正解のある本物の回答です。

ついでに ls も実行し、履歴保存のために exit してVerifyを押してください。

周りを見る

  • 今どこにいる?
    • pwd
  • ここに何がある?
    • ls
  • 隠しファイルも含めて
    • ls -a
  • 詳細付き——先頭の d はディレクトリの意味
    • ls -l
  • 移動せずに他のフォルダの中身を見る
    • ls ~/Documents
