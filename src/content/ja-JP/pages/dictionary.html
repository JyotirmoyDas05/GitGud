以下はGit Gudのチャレンジで使用するターミナルコマンドとGitコマンドです。

Bash/ターミナルの基本

  • 現在いるフォルダーを表示します（作業ディレクトリーの表示）
    • pwd
  • フォルダー内の項目を一覧表示します
    • ls
  • 隠し項目を含めてすべて一覧表示します
    • ls -a
  • 詳細付きで一覧表示します — 先頭のdはディレクトリーを意味します
    • ls -l
  • 既存のフォルダーに移動します（ディレクトリーの変更）
    • cd <FOLDERNAME>
  • 親フォルダーに移動します
    • cd ..
  • ホームディレクトリーに移動します
    • cd ~
  • 前のフォルダーに戻ります
    • cd -
  • 新しいフォルダーを作成します（ディレクトリーの作成）
    • mkdir <FOLDERNAME>
  • 複数のフォルダーを一括で作成します
    • mkdir -p <A>/<B>/<C>
  • 空のファイルを作成します
    • touch <FILENAME>
  • 文字をそのまま表示します
    • echo hello
  • 画面をクリアします（何も削除されません）
    • clear
  • ターミナルを終了します
    • exit
  • コマンドの使い方を確認します
    • <COMMAND> --help

どのコマンドよりも重要な2つのキー： Tabは入力途中の ファイル名やフォルダー名を補完します。up arrowは以前に 入力した内容を呼び戻します。

Gitの設定

  • Gitのバージョンを確認します
    • git --version
  • 名前を設定します
    • git config --global user.name "Your Name"
  • メールアドレスを設定します
    • git config --global user.email youremail@example.com
  • Githubアカウントを設定します（大文字と小文字を区別します）
    • git config --global user.username uSeRnAmE

Gitの基本

  • フォルダーでGitを有効にします
    • git init
  • リポジトリーの変更状態を確認します
    • git status
  • ファイルの変更内容を表示します
    • git diff
  • ファイルの変更をコミット対象に追加します
    • git add <FILENAME>
  • すべてのファイルの変更を追加します
    • git add .
  • 追加した変更を内容を表す短いメッセージとともにコミット（保存）します
    • git commit -m "your commit message"
  • リポジトリーをご自身のコンピューターにコピーします
    • git clone <URL>

Gitのブランチ

  • 新しいブランチを作成します
    • git branch <BRANCHNAME>
  • ブランチに移動します
    • git checkout <BRANCHNAME>
  • ブランチの作成と切り替えを一行で行えます
    • git checkout -b <BRANCHNAME>
  • ブランチを一覧表示します
    • git branch
  • 現在いるブランチの名前を変更します
    • git branch -m <NEWBRANCHNAME>

Gitのリモート

  • リモート接続を追加します
    • git remote add <REMOTENAME> <URL>
  • リモートにURLを設定します
    • git remote set-url <REMOTENAME> <URL>
  • リモート接続を表示します
    • git remote -v

Gitでのプル

  • 変更を取り込みます
    • git pull
  • リモートブランチから変更を取り込みます
    • git pull <REMOTENAME> <REMOTEBRANCH>
  • プルする前にリモートの変更を確認します
    • git fetch --dry-run

Gitでのプッシュ & マージ

  • 変更をプッシュします
    • git push <REMOTENAME> <BRANCHNAME>
  • ブランチを現在のブランチにマージします
    • git merge <BRANCHNAME>

Gitでのリモートとブランチの削除

  • ローカルのブランチを削除します
    • git branch -D <BRANCHNAME>
  • リモートのブランチを削除します
    • git push <REMOTENAME> --delete <BRANCHNAME>
