Git Gudを始める前にインストールされた方も多いと思いますが、まだの方はこちらのリンクをご利用ください。

GitHub Desktopアプリを使えば、ターミナルでできることの多く（すべてではありません）ができ、場合によっては少し見やすくなります。個人的には、小さくないdiffを確認する際に使っています。変更内容が とても見やすく表示されます。
