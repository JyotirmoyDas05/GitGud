Voici les commandes de terminal et Git utilisées dans les défis de Git Gud.

Bases de Bash/Terminal

  • Afficher le dossier dans lequel vous vous trouvez (afficher le répertoire courant)
    • pwd
  • Lister les éléments d'un dossier
    • ls
  • Tout lister, y compris les éléments cachés
    • ls -a
  • Lister en détail — un d initial signifie répertoire
    • ls -l
  • Naviguer dans un dossier existant (changer de répertoire)
    • cd <FOLDERNAME>
  • Remonter au dossier parent
    • cd ..
  • Aller à votre répertoire personnel
    • cd ~
  • Revenir au dossier précédent
    • cd -
  • Créer un nouveau dossier (créer un répertoire)
    • mkdir <FOLDERNAME>
  • Créer toute une chaîne de dossiers d'un coup
    • mkdir -p <A>/<B>/<C>
  • Créer un fichier vide
    • touch <FILENAME>
  • Afficher quelque chose en retour
    • echo hello
  • Effacer la fenêtre (rien n'est supprimé)
    • clear
  • Fermer le terminal
    • exit
  • Demander à n'importe quelle commande ce qu'elle peut faire
    • <COMMAND> --help

Deux touches valent plus que n'importe quelle commande : Tab complète le nom de fichier ou de dossier que vous avez commencé à taper, et la touche up arrow rappelle ce que vous avez tapé précédemment.

Configuration de Git

  • Vérifier la version de Git
    • git --version
  • Configurer votre nom
    • git config --global user.name "Your Name"
  • Configurer votre email
    • git config --global user.email youremail@example.com
  • Configurer votre compte Github (case sensitive)
    • git config --global user.username uSeRnAmE

Bases de Git

  • Activer Git pour un dossier
    • git init
  • Vérifier l'état des changements dans un dossier
    • git status
  • Affichier les changements des fichiers
    • git diff
  • Ajouter les changements d'un fichier au prochain commit
    • git add <FILENAME>
  • Ajouter tous les changements
    • git add .
  • Pour soumettre (aka commit) les changements ajoutés avec un message de description
    • git commit -m "your commit message"
  • Copier un dépôt en local
    • git clone <URL>

Branches Git

  • Créer une nouvelle branche
    • git branch <BRANCHNAME>
  • Se déplacer sur une branche
    • git checkout <BRANCHNAME>
  • Créer et se déplacer sur la nouvelle branche
    • git checkout -b <BRANCHNAME>
  • Lister les branches
    • git branch
  • Renommer la branche courante
    • git branch -m <NEWBRANCHNAME>

Remotes Git

  • Ajouter un remote
    • git remote add <REMOTENAME> <URL>
  • Configurer l'URL vers un remote
    • git remote set-url <REMOTENAME> <URL>
  • Lister les remotes
    • git remote -v

Récupérer (pull) avec Git

  • Pull (tirer) les derniers changements
    • git pull
  • Pull les changement depuis une branche sur un remote
    • git pull <REMOTENAME> <REMOTEBRANCH>
  • Voir les changement avant de les tirer effectivement
    • git fetch --dry-run

Push & Merge avec Git

  • Push (pousser) les changements soumis
    • git push <REMOTENAME> <BRANCHNAME>
  • Merge une branche dans la branche courante
    • git merge <BRANCHNAME>

Supprimer des remotes et des branches avec Git

  • Suprimer une branche locale
    • git branch -D <BRANCHNAME>
  • Suprimer une branche distante
    • git push <REMOTENAME> --delete <BRANCHNAME>
