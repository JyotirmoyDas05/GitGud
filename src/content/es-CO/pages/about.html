Git Gud enseña los comandos de Git que los desarrolladores usan a diario, junto con el GitHub Flow — la forma en que la gente colabora en GitHub. Empieza antes que la mayoría de los tutoriales: los primeros cinco retos tratan sobre la propia terminal, porque "abre una terminal y ejecuta git init" no es una sola instrucción si nunca has abierto una terminal.

Algunos retos necesitan conexión a internet, así que conviene estar en línea para terminarlos. Siempre puedes abrir la aplicación y leer los retos y recursos sin conexión.

Un entorno de desarrollo real

Git Gud usa la terminal real, Git real y GitHub real en lugar de emularlos. Cuando termines tendrás repositorios reales en tu cuenta de GitHub y cuadros verdes en tu gráfico de contribuciones. Nada aquí es una simulación, y por eso cada reto se comprueba ejecutando Git contra tus propios repositorios — si un reto pasa, es que funcionó de verdad.

Lo que necesitas

Nada, para empezar — el módulo de terminal usa lo que tu computadora ya tiene. Después, Git y una cuenta de GitHub, en lo que dos de los retos te guían paso a paso. No necesitas Node.js, Python ni ningún otro entorno de ejecución — Git Gud se distribuye como una única aplicación nativa.

Sobre los retos de terminal

Comandos como pwd y ls no cambian nada en tu computadora, así que no hay ningún archivo que inspeccionar después para ver si los ejecutaste. Esos retos se comprueban leyendo el archivo de historial que tu propio shell guarda — ~/.bash_history y sus equivalentes para Zsh, Fish y PowerShell. Solo se leen las últimas cientos de líneas, todo ocurre en tu máquina, nada se envía a ningún sitio, y cada comprobación indica el archivo que leyó.

Cómo está construido

Git Gud es una Tauri aplicación: un backend en Rust que ejecuta Git y se comunica con GitHub, y una interfaz en React renderizada por la propia vista web del sistema operativo. No incluye ningún motor de navegador, por eso la descarga se mide en megabytes en lugar de cientos de ellos.

El repositorio complementario que bifurcas durante los retos es git-gud-verifywork. Su automatización se ejecuta por completo en GitHub Actions — no hay ningún servidor que pueda caerse.

Créditos

Git Gud es una adaptación de Git-it, una aplicación Electron escrita por @jlord y muchos colaboradores, publicada bajo la licencia BSD 2-Clause. La estructura de los retos y gran parte de los textos son suyos. Esta versión reconstruye la aplicación sobre Tauri, sustituye el servicio de verificación retirado por GitHub Actions y corrige varias comprobaciones que habían dejado de funcionar a medida que Git y GitHub cambiaron.

El diseño de la interfaz toma prestado su sistema de tokens de T3 Code, usado bajo la licencia MIT.
