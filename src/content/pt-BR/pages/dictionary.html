Abaixo estão os comandos de terminal e Git usados nos desafios do Git Gud.

Básico de Bash/Terminal

  • Mostre a pasta onde você está (print working directory)
    • pwd
  • Liste os itens de uma pasta
    • ls
  • Liste tudo, incluindo itens ocultos
    • ls -a
  • Liste com detalhes — um d no início significa diretório
    • ls -l
  • Entre em uma pasta existente (ou seja, mude de diretório)
    • cd <FOLDERNAME>
  • Suba para a pasta pai
    • cd ..
  • Vá para o seu diretório home
    • cd ~
  • Volte para a pasta anterior
    • cd -
  • Crie uma nova pasta (ou seja, make directory)
    • mkdir <FOLDERNAME>
  • Crie uma cadeia inteira de pastas de uma vez
    • mkdir -p <A>/<B>/<C>
  • Crie um arquivo vazio
    • touch <FILENAME>
  • Imprima algo de volta para você
    • echo hello
  • Limpe a janela (nada é apagado)
    • clear
  • Feche o terminal
    • exit
  • Pergunte a qualquer comando o que ele sabe fazer
    • <COMMAND> --help

Duas teclas que valem mais que qualquer comando: Tab completa o nome do arquivo ou pasta que você começou a digitar, e a up arrow traz de volta o que você digitou antes.

Configurando o Git

  • Verifique a versão do Git
    • git --version
  • Defina seu nome
    • git config --global user.name "Your Name"
  • Defina seu e-mail
    • git config --global user.email youremail@example.com
  • Defina sua conta do Github (sensível a maiúsculas e minúsculas)
    • git config --global user.username uSeRnAmE

Básico de Git

  • Ative o Git para uma pasta
    • git init
  • Verifique o status das mudanças em um repositório
    • git status
  • Veja as mudanças nos arquivos
    • git diff
  • Adicione as mudanças de um arquivo para serem commitadas
    • git add <FILENAME>
  • Para adicionar as mudanças de todos os arquivos
    • git add .
  • Para commitar (ou seja, salvar) as mudanças que você adicionou, com uma mensagem curta descrevendo as mudanças
    • git commit -m "your commit message"
  • Copie um repositório para o seu computador
    • git clone <URL>

Branches no Git

  • Crie uma nova branch
    • git branch <BRANCHNAME>
  • Mude para uma branch
    • git checkout <BRANCHNAME>
  • Você pode criar e mudar para uma branch em uma linha só
    • git checkout -b <BRANCHNAME>
  • Liste as branches
    • git branch
  • Renomeie a branch onde você está
    • git branch -m <NEWBRANCHNAME>

Remotos no Git

  • Adicione conexões remotas
    • git remote add <REMOTENAME> <URL>
  • Defina uma URL para um remoto
    • git remote set-url <REMOTENAME> <URL>
  • Veja as conexões remotas
    • git remote -v

Fazendo pull no Git

  • Baixe as mudanças
    • git pull
  • Baixe as mudanças de uma branch remota
    • git pull <REMOTENAME> <REMOTEBRANCH>
  • Veja as mudanças no remoto antes de baixá-las
    • git fetch --dry-run

Push & Merge no Git

  • Envie as mudanças
    • git push <REMOTENAME> <BRANCHNAME>
  • Faça merge de uma branch na branch atual
    • git merge <BRANCHNAME>

Excluindo remotos e branches no Git

  • Exclua uma branch local
    • git branch -D <BRANCHNAME>
  • Exclua uma branch remota
    • git push <REMOTENAME> --delete <BRANCHNAME>
