GitHub Desktop

Você provavelmente instalou isso antes de começar o Git Gud, mas se não instalou, aqui está o link.

O aplicativo GitHub Desktop permite fazer muito do que dá para fazer no terminal (embora não tudo) e às vezes é um pouco mais fácil de ler. Pessoalmente, eu o uso para revisar qualquer diff meu que não seja pequeno. Suas mudanças ficam muito boas de ver desse jeito.

  • Github Desktop (OSX, Windows) Grátis por GitHub
  • Github Desktop Guides por GitHub

Você pode ver mais aplicativos desktop de git no site do Git: Git GUIs
