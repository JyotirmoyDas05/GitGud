Aprenda as três partes de que todo comando é feito e como perguntar a um comando o que ele sabe fazer.

Comando, Argumentos, Opções

Toda linha que você digita em um prompt tem o mesmo formato. Uma vez que você enxerga isso, comandos desconhecidos param de parecer feitiços e começam a parecer frases.

command [options] [arguments]

  • O comando é o verbo — o programa que você quer executar. Ele sempre vem primeiro. ls, echo, git.
  • Argumentos são sobre o que o comando deve agir. O substantivo. Em cd Documents, o argumento é Documents.
  • Opções (também chamadas de flags ou switches) mudam como o comando se comporta. Elas começam com um traço: -a, -l, --help.

Então ls -l Documents se lê como: liste (comando), do jeito detalhado (opção), a pasta Documents (argumento). Três partes, separadas por espaços.

Esse espaçamento importa mais do que iniciantes esperam. ls-l é uma palavra só e o shell vai dizer que esse comando não existe. Os espaços são como o shell sabe onde uma parte termina e a próxima começa.

Opções Curtas e Longas

A maioria das opções vem em duas grafias para a mesma coisa:

  • Curta, um traço e uma letra: -a. Rápida de digitar. Normalmente pode ser combinada — ls -la significa -l e -a juntas.
  • Longa, dois traços e uma palavra: --all. Mais lenta de digitar, mas você consegue ler daqui a seis meses e saber o que ela fez.

Use as curtas quando estiver digitando, as longas quando estiver escrevendo algo para outra pessoa — incluindo você do futuro.

Um Comando Com Argumento

echo faz exatamente uma coisa: ele devolve o que você der para ele.

echo hello

hello

Sozinho, echo sem nada depois mostra uma linha vazia — o comando sem argumento não tem nada a dizer. Dê várias palavras para ele e ele mostra todas:

echo I am talking to my computer

Parece inútil. Não é: echo é como você confere o que algo contém antes de fazer qualquer coisa arriscada com isso, e é a primeira coisa que você vai usar quando um script não estiver fazendo o que você esperava.

Um Comando Com Opção

ls lista o que está na pasta onde você está parado agora. Tente sem nada primeiro:

ls

Agora adicione uma opção e veja o mesmo comando responder de outro jeito:

ls -a

-a é a forma curta de all, e de repente aparecem entradas extras começando com ponto — .bashrc, .gitconfig. Um ponto no começo significa "oculto", e oculto só significa que o ls pula esses arquivos a menos que peçam. Não há permissão envolvida; são arquivos comuns com um nome discreto. O Git guarda seu repositório inteiro em um deles, que é um truque que você vai conhecer mais adiante.

Mais um:

ls -l

-l é long — um item por linha, com seu tamanho e quando foi alterado pela última vez. Mesmo comando, mesma pasta, uma quantidade diferente de detalhe, porque você pediu.

E como opções curtas se combinam, isso faz as duas coisas de uma vez:

ls -la

Pergunte ao Próprio Comando

Ninguém decora opções. O que pessoas experientes realmente fazem é perguntar, e quase todo comando responde à mesma pergunta:

ls --help

Sai uma parede de texto. Não leia tudo — leia as primeiras linhas, que dizem para que o comando serve, depois passe o olho na lista de opções à esquerda até algo parecer o que você quer. Essa é a habilidade: passar o olho, não decorar.

Tente com um comando que você nunca usou na vida:

mkdir --help

Você agora sabe o que mkdir faz e mais ou menos como usar, sem ninguém ter explicado. Esse é o truque que faz o terminal ser algo que dá para aprender em vez de uma lista de coisas para decorar — e você vai conhecer o mkdir direito daqui a dois desafios.

No macOS, alguns comandos respondem a man ls em vez de --help — man é a forma curta de manual. Pressione q para sair.

Limpando a Bagunça

Depois de tanta saída, a janela está uma bagunça. Um comando resolve:

clear

Nada é apagado — seu histórico continua intacto e a seta para cima ainda funciona. Ele só rola a sujeira para fora do caminho para você conseguir pensar.

Quando você tiver executado echo com algo a dizer, ls com uma opção, e --help em qualquer coisa, feche o terminal com exit para que seu shell salve o histórico, depois pressione Verificar.

O Formato, Sempre

  • Comando sozinho
    • ls
  • Comando com opção
    • ls -a
  • Comando com argumento
    • echo hello
  • Os três juntos
    • ls -l Documents
  • Pergunte a um comando o que ele faz
    • ls --help
