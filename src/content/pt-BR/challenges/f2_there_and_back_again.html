Navegue pelo sistema de arquivos com cd — desça para dentro das pastas, volte para o pai e direto para casa de novo.

Mudando de Diretório

Você sabe onde está. Agora precisa estar em outro lugar. Um comando resolve:

cd <WHERE>

cd é change directory. É o equivalente no terminal de clicar duas vezes em uma pasta, e é o comando que você vai digitar mais do que qualquer outro pelo resto da sua vida.

Ele não mostra nada quando funciona. Esse silêncio é normal e é de propósito — no terminal, sem notícias é boa notícia. Comandos falam quando algo dá errado. Sua prova de que funcionou é o prompt, que agora mostra a nova pasta, e o pwd, que vai confirmar.

Desça Para Dentro de Uma Pasta

Comece em casa e veja o que há lá:

cd ~ ls

Escolha qualquer pasta que você viu — Documents e Desktop existem em quase toda máquina — e entre nela:

cd Documents

Olhe o prompt. Ele mudou. Confirme direito:

pwd

/Users/jyoti/Documents

Você acabou de usar um caminho relativo. Você digitou Documents, não o endereço inteiro, e funcionou porque o cd procurou aquele nome começando de onde você já estava. Caminhos relativos são curtos, e significam coisas diferentes dependendo de onde você está parado — que é exatamente a graça.

Digite cd Doc e pressione Tab. O shell completa a palavra para você. Isso é o autocompletar com tab, funciona em todo caminho que você for digitar, e livra você de erros de digitação além de teclas. Pegue o hábito agora — é a diferença entre quem acha o terminal tedioso e quem não acha.

Volte Para Cima

Todo diretório tem um pai — aquele que contém ele. Ele tem um atalho permanente, dois pontos:

cd .. pwd

Você está de volta onde começou. .. sempre significa "um nível para cima, daqui", então funciona em qualquer lugar sem saber nome nenhum.

Existe um atalho correspondente para o contrário: um ponto só, ., significa "bem aqui". Parece inútil — até você conhecer um comando que precisa que você diga "esta pasta" em voz alta. git add ., que você vai digitar muitas vezes mais adiante, é exatamente isso.

Pontos se acumulam. Isso sobe dois níveis:

cd ../..

E eles se combinam com nomes. Subir um nível e depois descer para uma pasta irmã, em um único movimento:

cd ../Downloads

Esse é o vocabulário inteiro. Um caminho é só esses pedaços juntos com barras.

Absoluto e Relativo

Dois tipos de caminho, e saber qual você está segurando acaba com a maior parte da confusão com caminhos para sempre.

  • Um caminho absoluto começa do topo do sistema de arquivos e é completo sozinho: /Users/jyoti/Documents. Significa a mesma coisa digitado de qualquer lugar. Você consegue reconhecer na hora — começa com / (ou ~, que se expande para um, ou uma letra de drive como C: no Windows).
  • Um caminho relativo começa de onde você está: Documents, ../Downloads, notes/day-one.txt. Mais curto de digitar, mas só está certo a partir do ponto de partida certo.

Pense como um endereço de rua versus "a segunda porta à esquerda". Os dois levam você lá. Só um deles continua funcionando quando repetido para alguém parado em outro lugar.

Use caminhos relativos para qualquer coisa por perto — que é na maior parte do tempo. Use um caminho absoluto quando estiver pulando para algum lugar longe, ou quando estiver anotando o caminho para outra pessoa.

Pule Para Qualquer Lugar

Passeie até alguns níveis para baixo, depois volte para casa em um movimento:

cd ~

cd sem nada depois faz a mesma coisa — casa é o destino padrão, porque é para onde você vai querer ir com frequência suficiente para merecer o atalho.

E um caminho absoluto leva você a qualquer lugar em um passo, não importa a distância:

cd ~/Documents

Isso é absoluto — o ~ se expande para o endereço completo do seu diretório home antes do cd sequer ver. No macOS ou Linux você também pode mirar bem no topo de todo o sistema de arquivos e dar uma olhada; nada lá vai morder você.

cd / ls

Um último atalho que vale ter:

cd -

Isso leva você de volta ao diretório anterior, como o botão de voltar do navegador. Dois desses em sequência e você fica alternando entre duas pastas — que é a maior parte do que o trabalho de verdade parece.

O Que É Verificado

Este desafio procura quatro formatos diferentes de cd no seu histórico do shell — um para cada ideia acima — em vez de quatro destinos específicos, então você pode praticar com as pastas que você realmente tem:

  • cd Documents — descer para uma pasta pelo nome (relativo)
  • cd .. — subir para o pai
  • cd ~ — home
  • cd ~/Documents ou cd /usr — um caminho absoluto

Execute pwd depois de cada um para ver funcionando. Depois exit para salvar seu histórico e pressione Verificar.

Navegando

  • Para dentro de uma pasta
    • cd <FOLDERNAME>
  • Para o pai
    • cd ..
  • Dois para cima, ou um para cima e para o lado
    • cd ../../
  • Home
    • cd ~
  • De volta para onde você estava
    • cd -
  • E sempre, quando estiver em dúvida
    • pwd
