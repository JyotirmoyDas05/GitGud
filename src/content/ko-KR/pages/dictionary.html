아래는 Git Gud 챌린지에서 사용하는 터미널 명령어와 Git 명령어입니다.

Bash/터미널 기본

  • 현재 있는 폴더를 표시합니다(작업 디렉터리 표시)
    • pwd
  • 폴더 안의 항목을 나열합니다
    • ls
  • 숨긴 항목을 포함해 모두 나열합니다
    • ls -a
  • 자세히 나열합니다 — 앞의 d는 디렉터리를 의미합니다
    • ls -l
  • 기존 폴더로 이동합니다(디렉터리 변경)
    • cd <FOLDERNAME>
  • 상위 폴더로 이동합니다
    • cd ..
  • 홈 디렉터리로 이동합니다
    • cd ~
  • 이전 폴더로 돌아갑니다
    • cd -
  • 새 폴더를 만듭니다(디렉터리 만들기)
    • mkdir <FOLDERNAME>
  • 여러 폴더를 한 번에 만듭니다
    • mkdir -p <A>/<B>/<C>
  • 빈 파일을 만듭니다
    • touch <FILENAME>
  • 문자를 그대로 표시합니다
    • echo hello
  • 화면을 지웁니다(삭제되는 것은 없습니다)
    • clear
  • 터미널을 종료합니다
    • exit
  • 명령어의 사용법을 확인합니다
    • <COMMAND> --help

어떤 명령어보다 중요한 두 개의 키: Tab은 입력 중인 파일이나 폴더 이름을 완성하고, up arrow는 이전에 입력한 내용을 다시 불러옵니다.

Git 설정

  • Git 버전을 확인합니다
    • git --version
  • 이름을 설정합니다
    • git config --global user.name "Your Name"
  • 이메일 주소를 설정합니다
    • git config --global user.email youremail@example.com
  • Github 계정을 설정합니다(대소문자를 구분합니다)
    • git config --global user.username uSeRnAmE

Git 기본

  • 폴더에서 Git을 유효하게 합니다
    • git init
  • 리포지토리의 변경 상태를 확인합니다
    • git status
  • 파일의 변경 내용을 표시합니다
    • git diff
  • 파일의 변경을 커밋 대상으로 추가합니다
    • git add <FILENAME>
  • 모든 파일의 변경을 추가합니다
    • git add .
  • 추가한 변경을 내용을 설명하는 짧은 메시지와 함께 커밋(저장)합니다
    • git commit -m "your commit message"
  • 리포지토리를 자신의 컴퓨터에 복사합니다
    • git clone <URL>

Git 브랜치

  • 새 브랜치를 만듭니다
    • git branch <BRANCHNAME>
  • 브랜치로 이동합니다
    • git checkout <BRANCHNAME>
  • 브랜치 만들기와 전환을 한 줄로 할 수 있습니다
    • git checkout -b <BRANCHNAME>
  • 브랜치를 나열합니다
    • git branch
  • 현재 있는 브랜치의 이름을 바꿉니다
    • git branch -m <NEWBRANCHNAME>

Git 리모트

  • 리모트 연결을 추가합니다
    • git remote add <REMOTENAME> <URL>
  • 리모트에 URL을 설정합니다
    • git remote set-url <REMOTENAME> <URL>
  • 리모트 연결을 표시합니다
    • git remote -v

Git에서 풀하기

  • 변경 내용을 가져옵니다
    • git pull
  • 리모트 브랜치에서 변경 내용을 가져옵니다
    • git pull <REMOTENAME> <REMOTEBRANCH>
  • 풀하기 전에 리모트의 변경 내용을 확인합니다
    • git fetch --dry-run

Git에서 푸시 & 머지

  • 변경 내용을 푸시합니다
    • git push <REMOTENAME> <BRANCHNAME>
  • 브랜치를 현재 브랜치에 머지합니다
    • git merge <BRANCHNAME>

Git에서 리모트와 브랜치 삭제하기

  • 로컬 브랜치를 삭제합니다
    • git branch -D <BRANCHNAME>
  • 리모트 브랜치를 삭제합니다
    • git push <REMOTENAME> --delete <BRANCHNAME>
