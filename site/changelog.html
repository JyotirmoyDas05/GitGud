Changelog

Everything shipped, in order.

Every entry below comes straight from the commit that made it — see CONTRIBUTING.md for why. The full text, unabridged, is in CHANGELOG.md ↗ and on GitHub Releases ↗.

  1. v0.2.3 Sept 22, 2026

    Search that finds what you meant.

    • AddedEvery matched word is highlighted, not just the first, and challenge titles are finally searchable — "githubbin" now finds its challenge.
    • AddedPlural matching, typo tolerance, stopword handling, and accent folding for all nine locales.
    • FixedA satisfied optional check now gets a tick, and result snippets highlight the right word.
  2. v0.2.2 Sept 22, 2026

    Linux gets a real installer.

    • Addedcurl | sh now installs the native .deb/.rpm for your distribution through its package manager, falling back to an AppImage only when it has to.
    • AddedIn-app updates work on .deb/.rpm installs, signed and verified the same way as every other platform.
    • AddedA themed confirmation dialog replaces the native OS alert for restart-to-update and clear-progress.
  3. v0.2.1 Sept 21, 2026

    One-line install, and a white-screen fix.

    • Addedcurl … | sh and irm … | iex one-line installs for macOS, Linux and Windows, resolved straight from the updater manifest.
    • AddedThe hero now shows the real home screen, with a parallax starfield and floating Git/GitHub marks.
    • FixedA WebKitGTK renderer crash that white-screened the app on a good number of Linux machines, hardest inside the AppImage.
  4. v0.2.0 Sept 20, 2026

    Two new modules, before Git even starts.

    • AddedThe Terminal and Files & Folders — five challenges verified against your real shell history and filesystem, not a checkbox.
    • AddedThis install website, a redesigned sidebar, in-app self-updates, and a changelog generated straight from commit messages.
    • FixedmacOS builds that silently never offered an update, failing Linux ARM builds, and a stale pass/fail list after navigating challenges.
  5. v0.1.0 Sept 19, 2026

    Initial release.

    • Added11 interactive Git & GitHub challenges, checked against real Git and GitHub state, with a live end-to-end verification engine.
    • Added9 locales, a mascot picker, command palette, and installers for Windows, macOS and Linux.

Older history and every raw commit are on the GitHub releases page ↗
